# ShipNest

Build a full-stack, production-grade e-commerce and logistics simulation platform called "ShipNest — Smart Logistics & Fulfillment".

🎨 DESIGN & COLOR SCHEME

═══════════════════════════════════════════════



The entire website must match this premium color palette:

- Primary Background: Deep Navy #0a0e1a

- Card Background: #0d1428

- Accent Gold: #c9a227 and #e8c547 (gradients)

- Silver/Text: #b8c5d6 and #d4e0ee

🔁 BUSINESS LOGIC RULES

═══════════════════════════════════════════════



1. Every new order ALWAYS starts with Step 1 (Order Placed, Prague, Czech Republic) auto-completed with current timestamp

2. Tracking ID format: SNX followed by 7 random digits (e.g. SNX4829371)

3. Order ID format: SN + last 8 digits of timestamp + 2 random digits (e.g. SN2024839271)

4. "Pay Now" button always succeeds — no real payment processing

5. Current order status = the text of the most recently completed tracking step

6. Progress bar % = completed steps ÷ total steps × 100

7. Estimated delivery auto-calculated as +7 days from order date (admin can override)

8. All copy buttons use navigator.clipboard.writeText() with a "Copied!" toast notification

9. All images must have onError fallback handlers

10. Admin changes save immediately and reflect in tracking page without page refresh
